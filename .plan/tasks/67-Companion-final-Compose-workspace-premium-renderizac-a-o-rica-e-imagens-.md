## Design Decisions Derived from the Reference
- Midnight blue catalog: background #091018 / surface #13212E / accent #65B8FF. Plum workspace: #150F1D / #21162C / #2B1D38, accent #D3A6FF / muted #BCA9C8 / onSurface #F9EFFF. Plum gradient from reference; centralized immutable tokens easy to override, avoiding automatic dynamicColor.
- System sans/mono offline typography: display 34–44sp tight, readable body 16sp, utility 12–13sp; do not pretend Avenir is installed or copy inaccessible 8px utility text. Shape 22/24dp, spacing 12/16/24dp, and 48dp hit targets.
- Signature: card expands into FULLSCREEN workspace overlaying retained catalog, not a bottomsheet. Reference timings/easing centralized (500ms open, 380ms close, moderate staged reveal), zero decorative wait when reduced motion is enabled. No effects re-trigger on streaming/recomposition.
- Right swipe tracks finger with axis lock; canceling preserves chat, RAM draft, selection, scroll, and tool folds; committing reveals catalog at the exact resting scroll/frame before invoking back navigation. Selection gestures, horizontal code scrolling, and IME take precedence. Back navigation, accessibility, reduced motion, rotation, and rapid close/reopen do not leave stale callbacks altering routes.

## Out of Scope and Limitations
No backend / provider / profile / HMR / services / Tailscale / TTL / Web fallback / installed runtimes or broad tool registration. PC DSH/LLMs remain; no takeover / hot injection / resume / retry. TUI session/profiles used for renderer/catalog source reference only; app remains preset companion / session-tool-only.
