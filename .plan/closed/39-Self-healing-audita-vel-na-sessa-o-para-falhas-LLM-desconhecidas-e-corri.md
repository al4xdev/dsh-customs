# Auditable in-session self-healing for unknown and correctable LLM failures

## Request and goal
User explicitly distinguishes an agent from a synchronous LLM call: automatic retry resolves obvious causes; complex failure should become an error observation within the session itself for the agent to analyze/repair/continue, with history preserved for auditing. Consuming subscription quota is authorized. Reuse goal 4132625b revision 5 armed; do not create a parallel objective. Tasks 36/38 remain independent, source/candidates frozen, and promotion only with receipts; this task makes no real calls and does not enable credits.

## Verified public seam
Host dsh-agent-loop settlement of failed attempt occurs before agent/request-error and before CLIENT dispatch. Retry action rebuilds prepareRequest/llm.prepareCall and rederives session.deriveMessages on each attempt. Assembly/tools/renderedPrompt of the original decision are not rebuilt; therefore do not promise that the model can fix a rejected schema prior to any inference. agent.steer/inject enqueue next-step, not serving retry within the same step. Followup after agent/error arrives after the goal-driver disarms activation.
