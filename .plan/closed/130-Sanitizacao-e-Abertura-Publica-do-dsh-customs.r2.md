# Task: Sanitization and Open Source Preparation for dsh-customs

## Overview and Objective
Prepare the `dsh-customs` repository for public release while preserving its monorepo/experimental lab character without leaking sensitive information, without enforcing machine-specific paths (`/home/alex`), and documenting all active environment variables and plugin requirements.

---

## 1. Mapping User Hardcodes and Local Paths (`alex`, `/home/alex`)

### A. Critical absolute paths in runtime code
* **`plugins/companion-api/local-model-descriptors.mjs`** and **`local-model-variants.mjs`**:
  * Hardcoded paths to HuggingFace GGUF snapshots: `/home/alex/.cache/huggingface/hub/...`
  * *Action:* Make configurable via environment variables (`DSH_LOCAL_GEMMA_ID`, `DSH_LOCAL_GEMMA_STYLETUNE_ID`).
* **`plugins/cordis.patch.yml`** and **`plugins/managed-plans/isolated-core.patch.yml`**:
  * Absolute paths in `name: /home/alex/git/my/dsh-customs/...`
  * *Action:* Use profile-relative paths or paths generated by the activation script (`tools/activate.mjs`).
* **`plugins/llm-resilience/lib/index-v*.mjs`** and **`plugins/agent-self-heal/lib/index-v*.mjs`**:
  * Hardcoded fallbacks to `"/home/alex/.local/share/dsh-cli/package.json"`.
  * *Action:* Use `process.env.XDG_DATA_HOME || path.join(os.homedir(), '.local/share')`.
* **`frontend/mobile-companion/deploy/dsh-mobile-companion.service`**:
  * `WorkingDirectory=/home/alex/git/my/dsh-customs/frontend/mobile-companion`
  * *Action:* Use standard systemd user specifier `%h`.

### B. Tooling and test scripts (`tools/`)
* Several utilities (`tools/installation-consolidation/cold.mjs`, `tools/task10-profile/promotion.mjs`, `tools/pi-ai-fork/host-install.mjs`) used `/home/alex` as fallback defaults.
* *Action:* Switch fallback to `process.env.HOME || os.homedir()`.

### C. Package names and branding
* Root `package.json`: `"name": "alex-dsh-machine-tools"`
* `frontend/mobile-companion/package.json`: `"name": "@alex/mobile-companion"`
* `android/companion`: package namespace `dev.alex.dsh.companion` (standard author identifier accepted in open source).

## 3. Environment Variables Catalog

Create a `.env.example` file and a corresponding section in `README.md` documenting:

### A. Paths & Base Directories
* `DSH_HOME`: DSH configuration and profiles directory (Default: `~/.dsh`).
* `XDG_DATA_HOME`: DSH runtime and packages data root (Default: `~/.local/share`).
* `XDG_CACHE_HOME`: Cache directory (Default: `~/.cache`).

### B. Companion & Remote Connectivity
* `DSH_COMPANION_ORIGIN`: Public HTTPS base URL for Companion (replaces Tailscale hardcode).
* `DSH_COMPANION_HOST`: Host authority expected on headers.
* `DSH_COMPANION_CLI`: Custom path to DSH companion executable.
* `DSH_RUNTIME_NODE_MODULES`: Runtime node_modules path.

### C. Local LLM & Models
* `DSH_LOCAL_URL`: Local inference server URL (Default: `http://127.0.0.1:8080/v1`).
* `DSH_LOCAL_MODEL`: Selected model ID when multiple are advertised.
* `DSH_DEFAULT_PROVIDER`: Default provider (Default: `openai-codex`).
* `DSH_DEFAULT_MODEL`: Default model.
* `DSH_DEFAULT_EFFORT`: Default reasoning effort (Default: `low`).

### D. Specific Plugins
* `CONTEXT7_API_KEY`: Documentation API token for `research`.
* `SIMP_MCP_PROJECT`: Audio project directory for `music` (Default: `~/git/my/simp_mcp`).
* `SIMP_MCP_UV`: uv binary for `music` (Default: `uv`).
* `LLAMACPP_BASE_URL`: llama.cpp backend URL for `grammar-fix` (Default: `http://127.0.0.1:8080`).
* `GRAMMAR_GPT_MODEL`, `GRAMMAR_GEMINI_MODEL`, `GRAMMAR_LOCAL_MODEL`: Models for `grammar-fix`.
* `PROJECT_MCP_TEST_LOG`: MCP test log path.
