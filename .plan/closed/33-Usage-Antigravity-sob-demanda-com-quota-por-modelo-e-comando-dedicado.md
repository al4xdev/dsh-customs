## Data and interpretation
MVP uses existing endpoint `/v1internal:fetchAvailableModels` and fields `models[id].quotaInfo.remainingFraction/resetTime`, without a new summary endpoint or guessed root window. Safe namespace: source, observedAtMs, stale/status/error code allowlisted, rows id/name/fraction?/resetAtMs?/window unknown. Fraction [0,1] finite, zero distinct from absent/unknown, invalid does not turn into 0/100. Display small >0 as <1% instead of 0%. Reset accepts explicit RFC3339 timezone validated to epoch-ms, invalid unknown; past shows past / needs refresh, does not invent now+5h. Do not infer five-hour/weekly from distance to reset, plan, or 429. Do not sum potentially shared variants. Display of names/ids normalized/bounded against control/ANSI chars; body/headers/email/project/token/tiers/clientsecret never enter DTO/text/log.

## Transport/lifecycle
Reuse provider's credential manager and authorized endpoint for metadata, without inference, new onboarding, account/model rotation, or billing/overage. Future query executed when user invokes command/service; do not add polling / startup calls / extra quota auto-refresh. Existing OAuth credentials may be refreshed by the manager (refresh may persist token): read-only refers to metadata/quota/billing, not a promise of zero refresh writes.

Bounded fetch (e.g., 10s total including credential wait), body limit e.g. 1MiB, rows limit e.g. 256, existing allowlisted endpoints. Prefer safe transport helper without altering catalogue/inference semantics; do not take fallback 403/429 as a way to evade quota (fail sanitized, fallback only for absent/unavailable endpoint explicitly chosen). Error reporting uses safe codes/status without raw error.message. Cache TTL 60s, explicit force refresh, single-flight; fresh/immutable detached results; stale identifiable without confusing with current quota. Cancellation for caller+lifetime, timeout, cleanup/drain; one waiter cancellation does not cancel others, all cancels/dispose abort transport. Invalidate cache on credentials/reference-updated/logout and prevent publishing results from old generation/account; test OAuth refresh / invalidation race (own token refresh must not reveal previous account's cache). Source does not trigger secret read on availability or registration. Usage failure does not break inference.

Current TUI may supply signal without binding to cancel key: do not promise immediate key cancel; own deadline ensures not waiting hours. Native registry grants/scope remain, no bypass of permissions.
